# VideoIA — Cloud Build

Projet Android prêt pour GitHub Actions.

Depuis un téléphone:
1. Créer un dépôt GitHub.
2. Envoyer tout le contenu de ce dossier.
3. Ouvrir Actions > Build VideoIA APK.
4. Run workflow.
5. Ouvrir le run terminé et télécharger VideoIA-debug-apk.
6. Extraire app-debug.apk et l'installer sur Android.

Cette APK est la version interface/prototype. La génération IA réelle nécessite encore un backend avec des moteurs IA et FFmpeg.
